How Wireshark Tracks Visited Websites & Users

              Deep Packet Inspection (DPI) & Metadata Extraction
            

          

          
        

        

          

            Key SOC Insight:
            

              Even though 98% of web traffic today is encrypted using HTTPS/TLS, Wireshark can still accurately track which websites are being visited and which user is visiting them without needing decryption keys or SSL proxies!
            

          


          

            

              

                1️⃣
                
DNS Resolution (UDP Port 53)

              

              

                Before any device connects to a website, the OS asks the DNS server (or hotspot gateway) to convert the domain name (e.g., youtube.com) into an IP address.
              

              

                Src: 10.101.133.29 ➔ Dst: 8.8.8.8

                DNS Query: "A youtube.com"
              

            


            

              

                2️⃣
                
TLS SNI Extension (TCP Port 443)

              

              

                During the TLS handshake (RFC 6066), the browser sends the Server Name Indication (SNI) in plain text so the web server serves the correct SSL certificate.
              

              

                ClientHello (TLSv1.3)

                Extension: server_name: "github.com"
              

            

          


          

            

              3️⃣
              
User & Device Attribution

            

            

              Every captured IP packet contains a Source IP address (e.g. 10.101.133.29). The dashboard correlates this IP with:
            

            
    
              
  • Local Host / Hotspot Discovery: Current machine (10.101.133.29) and gateway (10.101.133.176).
    • 
              
  • Nessus Scan Targets: Correlated against Tenable Nessus host catalog and NetBIOS/DNS hostnames.
    • 
              
  • Layer 2 MAC Addresses: Derived from Ethernet frames for physical hardware manufacturer identification.
